# Aplikasi-JARA_C1_kelompok-11
Aplikasi web untuk mengelola tugas tim atau pribadi
## 1. Spesifikasi Kebutuhan Fungsional (Functional Requirements)

**PERTEMUAN 2** PM = Arga

Berikut adalah daftar kebutuhan fungsional sistem yang telah dipetakan berdasarkan modul dan penanggung jawab pengembangannya:

| ID | Deskripsi Kebutuhan Fungsional | Penanggung Jawab |
|---|---|---|
| **FR-01** | Sistem dapat mengelola tugas tim atau pribadi. | Arga |
| **FR-02** | Pengguna dapat membuat tugas baru. | Arga |
| **FR-03** | Pengguna dapat mengelompokkan tugas. | Arga |
| **FR-04** | Pengguna dapat mengatur tugas ke dalam beberapa daftar (list). | Haikal |
| **FR-05** | Pengguna dapat menetapkan prioritas waktu pada tugas. | Haikal |
| **FR-06** | Pengguna dapat menandai tugas yang sudah selesai. | Haikal |
| **FR-07** | Pemilik daftar dapat menambahkan pengguna lain ke dalam sistem/daftar. | Yoga |
| **FR-08** | Pemilik daftar dapat memantau perkembangan (progress) pengguna lain. | Yoga |
| **FR-09** | Admin dapat menambahkan dan menghapus akun pengguna lain di dalam sistem. | Yoga |
